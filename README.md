# Sistema de Gestión de Recursos Humanos — Minería

Sistema de gestión de Recursos Humanos desarrollado en Microsoft Excel, orientado a la organización, administración y consulta de información relacionada con el personal de la Dirección General de Minería.

El proyecto utiliza un archivo habilitado para macros (`.xlsm`) y diferentes hojas de trabajo, formularios y plantillas para estructurar la información del personal y facilitar su gestión administrativa.

## Descripción

El sistema centraliza información personal, laboral y administrativa de los empleados en una herramienta estructurada en Excel.

Su diseño busca facilitar el registro y consulta de información, mantener los datos organizados y proporcionar una estructura uniforme para la gestión de expedientes y registros del personal.

## Funcionalidades

* Registro y administración de empleados.
* Gestión de información personal y de contacto.
* Registro de datos de identificación.
* Administración de información laboral.
* Registro de cargos y grupos ocupacionales.
* Gestión de salarios iniciales y actuales.
* Registro de fechas de ingreso y salida.
* Gestión de información relacionada con AFP y ARS.
* Control de vacaciones disponibles.
* Registro de licencias médicas.
* Registro de faltas y amonestaciones.
* Gestión del estado laboral de los empleados.
* Registro y referencia de expedientes.
* Campo para observaciones administrativas.
* Generación y organización de fichas individuales.
* Uso de formularios y plantillas para presentar la información de cada empleado.
* Identificación de empleados mediante códigos internos.

### Hojas de trabajo

**Sheet1**
Hoja principal destinada al registro general de los empleados y almacenamiento de la información personal, laboral y administrativa.

**Form**
Formulario utilizado para organizar y presentar información correspondiente a un empleado.

**Hoja1**
Hoja auxiliar utilizada para el manejo y organización de información del sistema.

**Plantilla**
Plantilla destinada a estructurar la información individual de los empleados y facilitar la organización de sus expedientes.

## Requisitos

Para utilizar el sistema se requiere:

* Microsoft Excel con soporte para archivos `.xlsm`.
* Habilitar macros al abrir el archivo, cuando sea necesario para el funcionamiento de las funcionalidades automatizadas.

## Uso

1. Descargar o clonar el repositorio.
2. Abrir `Sistema-Gestion-RRHH-Mineria.xlsm` utilizando Microsoft Excel.
3. Habilitar las macros si el sistema lo solicita.
4. Utilizar las hojas, formularios y plantillas disponibles para gestionar la información.

## Seguridad y privacidad

El sistema está diseñado para trabajar con información personal y laboral, por lo que los datos utilizados deben manejarse de acuerdo con las políticas de privacidad y protección de datos correspondientes.

Si el proyecto se publica en un repositorio público, se recomienda utilizar únicamente datos ficticios, de prueba o previamente anonimizados.

No se deben publicar datos reales como:

* Documentos de identidad.
* Números telefónicos.
* Correos electrónicos personales.
* Información salarial.
* Información médica.
* Datos de AFP o ARS.
* Expedientes de empleados.
* Cualquier otra información que permita identificar directamente a una persona.
